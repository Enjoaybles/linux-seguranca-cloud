# Atividade Individual - Criação e Publicação de Serviço Web

Este repositório contém os ficheiros e a documentação técnica da atividade prática do Tópico 03.

## 🚀 Como testar este projeto localmente
1. Clona este repositório.
2. Copia o conteúdo da pasta `/site` para `/var/www/html` ou para a diretoria configurada no teu servidor web.
3. Garante que o Nginx ou Apache tem permissões de leitura para os ficheiros.
