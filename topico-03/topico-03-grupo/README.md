O grupo optou pela publicação de um pequeno site estático utilizando HTML, CSS e Nginx. A solução apresenta baixa complexidade, não requer tecnologias adicionais como PHP ou bases de dados e permite demonstrar de forma clara o processo de criação, publicação, validação e documentação de um serviço web em ambiente Linux.

A arquitetura proposta utiliza HTTP na porta 80 e o diretório /var/www/html/topico-03 como local de publicação. A validação será realizada através do navegador e do comando curl, garantindo que o serviço está operacional.
